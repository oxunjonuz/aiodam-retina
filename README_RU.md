# AIODAM Retina

Переносимый комплект пространственного восприятия, событий движения и истории
«действие → наблюдаемый результат» для LLM, работающих с дискретными сетками 64×64.

## Не один сенсор, а четыре дополняющих канала

1. **Global Color Sensor:** какие цвета присутствуют и как изменилось их количество.
2. **Текущая пространственная карта / Fovea:** где находятся цветовые компоненты,
   каковы их размеры и что видно в локальном участке. Работает и на первом кадре.
3. **Spatial/Event Retina:** что появилось и исчезло для каждого цвета, где это
   произошло; кандидаты движения, сдвига камеры и повторяющейся анимации.
4. **История действий и наблюдений:** что уже сделали и что получили после этого,
   с сохранением и восстановлением всей сессии.

ON/OFF — не включение нейросети и не оценка «истина/ложь». Это переход клетки
в принадлежность определённому цвету или выход из неё. На этих картах затем
строятся геометрия событий и сопоставления. Каналы работают совместно, а не
как обязательная цепочка «три стадии, потом один последний бинарный ответ».

## Что измерено

- В историческом аудите: **24 619 → 441 токен в среднем**, то есть **−98,2%**
  относительно двух полных текстовых сеток.
- **8,202 мс** на вызов исторического `observe`, 500 вызовов.
- **45/45** исходных проверок, **5/5** независимых проверок пакетов и
  **5/5** отклонённых намеренно испорченных координат.

Это экономия представления и скорость сенсора. Не процент побед и не прямой
тест против VLM. Сокращённый пакет не сохраняет всю исходную картинку без потерь.
Победные игровые применения описаны отдельно в [отчёте](docs/REPORT_RU.md).

## Запуск

```bash
python -m pip install -e .
python -m unittest discover -s tests -v
python tools/verify_historical_audit.py --eval-root evidence
python examples/demo.py
python tools/benchmark.py
```

Нужны Python 3.10+ и NumPy. Для демонстрации не нужны GPU, LLM, ключи и движок
ARC. Пример искусственный: он не изображает выигрыш в настоящей игре.

Основной интерфейс — `RetinaSession`: начальный кадр, затем выполненное действие
и реальный кадр после него. `to_prompt()` возвращает наблюдения для LLM,
`numeric_packet()` — 22 канала для числового потребителя,
`save()/load()` — полное сохранение и проверяемое восстановление.

Новый переносимый интерфейс не обрезает историю. Вся история передаётся в промпт,
кадры остаются в сохранённой сессии. Это не обещание бесконечного контекста:
размер и стоимость растут. У старого сериализатора есть ограничения сводки,
описанные отдельно; он не заменяет полную историю нового интерфейса.

## Границы

Компонента цвета не означает «игрок» или «стена». Изменение после действия ещё
не доказывает, что его вызвало действие: возможны анимация, таймер и камера.
Сенсор даёт измерения и кандидаты объяснений; причинные выводы и планирование
остаются задачей контроллера. Вычисляемый `delta` не всегда равен физическому
смещению объекта. См. [ограничения и историю](docs/REPORT_RU.md).

Перед публикацией нужно выбрать лицензию и проверить право распространять
включённые публичные кадры. Ключей, весов, частной памяти AIODAM и полных игровых
маршрутов в этой папке нет. Происхождение файлов: [PROVENANCE](docs/PROVENANCE.md).
